# Sample data



Seven (7) sequential \~4GB images from a digital voice recorder are available at Zenodo (DOI 10.5281/zenodo.20562700).



These files were part of an experiment to study deleted audio file decay on a digital voice recorder. 10 files were originally created, then deleted, then additional activity was performed using the device. Fragments of multiple files survived and were recovered. The fragments from these files were saved as new files with MP3 extensions, and the recovered fragments were played as MP3 files. A sample decay curve is included (all.pdf). See paper at AES Conference on Audio Forensics, Arlington, Virginia, June 15-17, 2017 (Jones, J. "Deleted Audio File Decay on a Digital Voice Recorder"), and thanks to the paper reviewer for noting the frame structure of MP3 and the fact that I did not need to add the MP3 header.
